# One-line review for make.fun

This is a program that writes one short text for make.fun's bounty `u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209`: it writes the single line its agent would post about its human on a rating site, straight into `entry.txt` with no trailing newline, and prints the character count.
